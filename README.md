# Brennvika Panorama – digital gjesteguide

Mobiltilpasset gjesteguide for Brennvika Panorama, driftet av Skoglund Heim AS.

## Publisering
Nettsiden er statisk og ligger i `index.html`. Den er laget for GitHub Pages fra `main`-branchens rotmappe.

## Viktig om Wi‑Fi
Dette repositoryet og GitHub Pages-nettstedet er offentlig. Et Wi‑Fi-passord som legges direkte i `index.html`, en QR-kode eller annen frontend-fil blir derfor offentlig tilgjengelig. Legg ikke inn et privat/langvarig Wi‑Fi-passord uten å akseptere dette.

## Bilder
Første versjon bruker et midlertidig ekte områdebilde fra Hamarøya/Vestfjorden via Wikimedia Commons. Dette skal erstattes av egne bilder fra Brennvika Panorama før endelig lansering.
